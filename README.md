# FitCat 3.27.0

PWA-дневник питания, воды, активности и изменений веса. HTML, CSS и JavaScript ES Modules; отдельная сборка и установка пакетов для GitHub Pages не нужны.

## Изменения 3.27.0

- Достижения получили встроенные SVG-значки с чёткими гранями, цветными материалами и мягким редким бликом. В профиле пять категорий в один ряд; все достижения открываются в горизонтальной ленте. Нажатие показывает условие получения. Щиты стабильности: 7, 30, 60 и 90 дней; максимальный — алмазный.
- Стили достижений и обучения включены в обязательные `styles/profile.css` и `styles/settings.css`. Отдельный `styles/engagement.css` и растровый атлас больше не используются. CSS-запросы имеют версию, чтобы первый запуск не подхватывал прежний файл из HTTP-кэша.
- Все стеклянные линзы используют один механизм: нижняя навигация, пол, цель, язык, вес/питание и существующие селекторы оформления. Свайп работает сразу; удержание лишь увеличивает стекло. Переход плавно продолжается из текущей позиции и не возвращается сначала к старому варианту. Предпросмотр не сохраняет промежуточные варианты, отпускание сохраняет один окончательный выбор.
- LDM сохраняет плавность функциональных переходов. Дорогие фоновые эффекты, размытия движущейся линзы и постоянные блики в LDM отключены. Движение линзы работает только до завершения перехода, затем кадры не запрашиваются.
- Обучение жестам компактное: три понятные карточки, тренировка с камерой, пропуск обучения и каждого шага. Включение/выключение находится только в окне обучения. В настройках остался один вход «Управление жестами». Открытие инструкции не запрашивает камеру.
- Все лимитные фоны и рамки, а также коллекционные рамки удалены из интерфейса и пакета. Основные рамки, PRO+ и четыре городских фона сохранены. Удалённый активный вариант безопасно заменяется базовым. Старые чеки остаются читаемыми; повторная покупка удалённой косметики невозможна. Баланс и история не переписываются, возврат монет автоматически не производится.
- «Графит» прилегает к фотографии без зазора. «Орбита» получила концентрические траектории и точно расположенные световые точки. Геометрия едина в профиле, шапке и предпросмотре.

## Обновление на GitHub Pages

1. Скачай резервную копию из настроек FitCat.
2. Распакуй ZIP. `index.html`, `sw.js`, `manifest.webmanifest`, `js`, `styles` и `assets` должны лежать в корне репозитория, без дополнительной внешней папки.
3. Обнови весь набор файлов вместе. Не ограничивайся одним `index.html`: особенно важны изменённые стили и новый `js/ui/achievement-art.js` и `js/core/retired-cosmetics.js`.
4. Старые каталоги `assets/profile-limited` и `assets/profile-frames` можно удалить из репозитория целиком. Остальные удалённые файлы перечислены в `REMOVED-FILES.txt`. Текущая версия на них не ссылается.
5. Если GitHub ограничивает загрузку 100 файлами, загружай `assets` отдельными вложенными папками; `js` и `styles` — отдельно.
6. Дождись завершения GitHub Pages, открой FitCat и нажми «Обновить» в баннере новой версии. При отсутствии баннера закрой и снова открой PWA с подключённым интернетом. Не очищай данные сайта и не удаляй PWA: профиль и дневник хранятся локально.

Service Worker `3.27.0-r1` проверяет SHA-256 всех ресурсов и сохраняет предыдущую полную версию при неполной загрузке обновления. Активация новой версии удаляет только старый кэш FitCat; `localStorage` не очищается.

## Что хранится и где

Профиль, фото, дневник, настройки, достижения, подписка и кошелёк — на устройстве. Для функции друзей текущий код использует Firebase: имя, дневные цели, сегодняшние продукты и вода доступны по ID. Поиск продуктов использует Open Food Facts, погода — Open-Meteo, жесты — MediaPipe Hands. Это внешние сетевые зависимости, и их доступность не обеспечивается локальным кэшем.

Камера запускается только после действия пользователя и останавливается при выключении жестов, уходе в фон, закрытии незавершённой тренировки или окончании PRO+. Во время тренировки жесты не изменяют реальную еду, воду или вкладки. В PWA шаги вводятся вручную.

## Разработчик и PRO+

`/dev` в имени локально однократно открывает PRO+ минимум на 99 лет, все достижения и значок разработчика, начисляет 999 999 коинов поверх баланса. Команда исчезает из отображаемого ника. Повторный ввод не начисляет деньги снова. Это локальная функция, без проверки роли на сервере. Встроенных промокодов для кошелька или подписки нет.

Покупки и подписка в этой версии — локальные данные. Реальная платёжная система не подключена. Тарифы: 29 / 649 / 1 999 коинов за 1 / 3 / 12 месяцев. Цена сохранённых городских фонов — 299 коинов.

## Разработка и проверки

`npm test` или `node --test tests/*.test.mjs` запускает проверки логики, событий интерфейса, сохранений, кошелька, обновления и завершения анимаций. Тестовый DOM не является браузером и не измеряет FPS.

После изменений ресурсов обнови версию `sw.js` и выполни `python3 tools/generate_precache_hashes.py`. Новые runtime-файлы также добавляй в `APP_FILES`.

Проверки 3.27.0: 482 теста пройдены. Реальная камера, доступность MediaPipe и плавность WebKit требуют проверки на iPhone. Сборка IPA в этот ZIP не входит.
